# Python Assignments Repository

This repository contains a collection of Python assignments and projects completed as part of college coursework. The assignments focus on data analysis, data cleaning, transformation, and visualization using popular Python libraries such as pandas, numpy, matplotlib, and seaborn.

## Repository Structure


## Assignments

### Assignment 1: Data Exploration Report
- Loading and exploring CSV datasets
- Dataset preview, size, and structure analysis
- Field information and data types
- Null value and duplicate analysis
- Numerical and categorical data analysis
- Statistical metrics calculation

### Assignment 2: Data Cleaning and Transformation
- Employee dataset cleaning
- Duplicate record removal
- Data transformation techniques
- Handling missing values
- Data type conversions

### Assignment 3: Data Visualization
- Creating various types of plots and charts
- Bar charts, histograms, scatter plots
- Heatmaps for correlation analysis
- Customizing plot aesthetics
- Saving and displaying visualizations

## Requirements

To run these assignments, you'll need the following Python packages:

```
pandas
numpy
matplotlib
seaborn
```

Install them using:
```bash
pip install -r requirements.txt
```

## Usage

Each assignment can be run independently:
```bash
python assignments/assignment_1.py
python assignments/assignment_2.py
python assignments/assignment_3.py
```

Note: The assignments reference specific CSV files that would need to be present in the specified paths or modified to use sample data.
